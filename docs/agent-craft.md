# Agent craft + research logic (locked, 2026-09-21)

## Universal craft logic (every agent)
1. Persona = 10-20yr expert with taste + output bar, never a title-only label.
2. Outcome-spec, never step-script: WHAT + quality bar + interfaces. Method is theirs.
3. Minimal allow-list reads; isolated session; no whole-repo scans.
4. Tools connect ONLY if the tool beats default-AI text on that exact task (verified). Bad tools banned — default AI + good prompt beats a bad integration every time. Text-only agents get zero tool connections by design.
5. Direction/executor split: locale (Syria) enters via direction inputs (refs, plans, style), never via tool searches. Tool searches are craft-only, always.
6. Output contract = small artifact (table/list), never dumps.
7. Trial-run micro-brief before track closes; PASS/notes recorded.

## Per-agent research phrases + craft
1. **director** (text-only, NO tools): "game director vision pillars scope arbitration techniques", "vertical slice scoping indie". Craft: deny edit/bash/all-MCP; verdict + cut list only.
2. **producer** (text-only, NO tools): "game production milestone planning solo developer", "indie task sizing story points gamedev". Craft: deny mutations; ordered S/M/L list + heavy flags only.
3. **world-quest** (bundled UE tools at execution): "open world quest pacing civilian stealth mission structure", "UE5 World Partition tile sizing open world", "UE5 PCG scattering tutorial", "OpenStreetMap to Unreal spline road workflow". Craft: reads maps/tables only; beats restricted to locked verb list.
4. **gameplay-tech** (bundled UE chain, PROVEN live): "UE5 Enhanced Input CharacterMovement crouch implementation", "Unreal Insights profiling CPU GPU guide", "UBT BuildCookRun headless cook automation", "UnrealEditor-Cmd ExecutePythonScript examples". Craft: ask-to-write, undoable + build-log proof, PLAY never counts alone.
5. **art-visual** (Blender live + general assets): "Blender to UE5 FBX export settings static mesh units", "trim sheet master material workflow Unreal Engine", "free CC0 PBR textures architecture Poly Haven AmbientCG", "Fab free packs shippable license Standard". NEVER "Syria/Middle-East kit". Craft: kit tables + LOD + proxies; import proof at execution.
6. **story** (text + sources): "writing civilian war stories games trauma-informed narrative design", "respectful war game narrative civilian dignity", "dialogue data tables Unreal data-driven". Facts via research agent per-scene. Craft: beats + tables only, never engine changes.
7. **camera** (bundled Sequencer at execution): "UE Sequencer cinematic blocking camera tutorial", "Mixamo to UE5 retarget free mocap", "in-engine cutscene additive animation layers". Craft: shot lists on game meshes only.
8. **sound** (libraries + delivery spec): "game audio adaptive ambience design FPS", "Freesound license commercial use", "ElevenLabs voice licensing game", "UE MetaSounds ambience implementation". Craft: asset lists + mix notes, loop-clean spec; never reads graphics code.
9. **tester** (bundled metrics, PROVEN pattern): "UE stat fps unit profiling checklist", "game QA bug triage crash-first method", "Unreal packaging common cook failures". Craft: read-only, FPS tables + repro steps, no fixes.
10. **research** (search + fetch only): "compare [A] vs [B] version compatibility 2026", "[license name] commercial game use", "[tool] Blender [version] UE [version] support". Craft: verdict tables ≤500 words, live-checked dates, traps + version-risks mandatory, one chain then STOP.

## Anti-patterns (banned)
- Locale-scoped tool searches ("Syria/Middle-East kit/tools").
- Connecting a tool because it exists; volume of tools ≠ quality.
- Whole-repo reads; parallel-agent stampedes; ratings asked of the owner on technical matters.
