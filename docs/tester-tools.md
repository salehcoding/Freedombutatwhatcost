# Track 7 — Tester chain (gates, budgets, honesty rule, trial PASS)

## Weekly 10-min gate (solo, free)
Packaged Dev build, Low 1080p, fixed 60s route, `stat unit + streaming` shot, `profilegpu` frame, FPS table. Insights only on regression/hitch. Device Profiles prove Low was real Low.

## Budgets (GTX1650-class min-spec)
60fps Low · <1200 draws · 1-1.5M tris · pool 1000-1400MB · 1-2 CSM, no HWRT · Lumen downsampled or baked fallback.

## Capture (free, local)
Crash Reporter local + debug files (Dev). Bug rows: BuildId, route, Low/Med, repro ≤3, expected/actual, stat numbers, log + dump paths. Scrape: Fatal/Ensure/Accessed-None/HLOD/pool/D3D-removed/Partition.

## Automation
Now: 1-2 Functional Tests via Session Frontend. Later: Gauntlet (after weekly cooks green). No paid SaaS, no trend DB solo.

## MCP split
AI: logs, stats, PIE control, screenshots, route runs, tables. Human: dignity/trauma look, hitch feel, aim feel, mix, final acceptance.

## Trial PASS (exemplary)
Crash-first, evidence quoted, repro marked Unknown instead of invented, numbers-needed column. Honesty rule holds.
