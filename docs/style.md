# Style — locked base + feel pillars (owner picks, manager owns rest)

## Base look: STALKER-grit, CoD approach
- Look: dusty pale sun, washed browns/grays, harsh daylight, dry air, realistic.
- Reference stack: STALKER 2 (open-world grit, zone dread, survival FPS) + Call of Duty (tight gunfeel, snappy movement, 60fps discipline, cinematic set-pieces).
- Lighting arc per slice: golden morning (Look-3 accent, breakfast) → dust gray (base, bombing) → lamp-lit night interiors (Look-2 accent, hiding). Base everything returns to: grit.
- Graphics: realistic. No stylization. Faces and streets must read true, not cartoon.

## Feel pillars (locked, manager enforces)
1. Never boring: every minute has tension or motion — dread, discovery, or action. No empty walking sim stretches.
2. Cinematics-heavy: in-engine Sequencer movies carry emotion between playable beats.
3. Immersive: first-person body sense, sound-led fear (jets before bombs), dust/smoke/light selling hits.
4. Guns (fighter chapters): CoD-tight — snappy ADS, readable recoil, punchy mix. Slice 1 has NO gun (child); gunfeel standard applies from fighter chapters on.
5. Movement: CoD-clean — sprint/slide/mantle responsive, no stickiness. Slice 1 movement = child-scaled (slower sprint, low camera, hide/crawl).
6. Feeling first: every beat must state its emotion; mechanics serve it, never reverse.

## Manager-discovers list (owner explicitly delegated)
Performance budgets, onboarding without tutorials signs, pacing curves, difficulty assist, audio mix targets, accessibility basics, testing gates. Proposed by manager/agents, never asked back as ratings.
