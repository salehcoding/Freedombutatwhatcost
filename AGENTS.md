# Freedom But At What Cost — Project Rules

## Vision (thin lock)
Open-world 3D FPS about Syrian civil war 2011-2024. Whole Syria is long-term vision. Start: ONE small district, emotional story, not just shooting. Player must feel sad, exciting, relatable. Accurate + respectful, no porn/nudity, no propaganda, civilian dignity first.

## Engine (locked)
Unreal Engine 5.8, local only, PC. No cloud builds. Free-first always. Pay only if free truly impossible for one critical thing.

## How we work (manager rules)
- Owner = user (idea + final yes/no + playtest eyes). Lead = OpenCode manager + on-call specialist agents.
- Best output > satisfying owner. Push back when idea hurts foundations.
- On-call roster, 1-3 active max. Never load whole project. Each agent gets allow-list reads only + own isolated context.
- Small slice first: District_01 only. World Partition on day 1, modular kit only, instancing everywhere, LOD/HLOD, scalable lighting, data-driven quests/dialogue.
- PLAY lies, COOK tells truth. Fake-test daily, real cook early for District_01. Target 60fps on Low profile weekly.
- Git from day 1. Light text work anytime, heavy cook/compile ask-first.

## Agent context rules (anti-bloat)
- Do NOT scan whole repo. Read only files listed in your task.
- Shared kernel only: this file + your task spec + your input/output contract.
- Output contract artifacts, not dumps. No full-project summaries in replies.
- Every mutation must be undoable, verified by read-back or build log.

## Sensitivity
Real war, real victims. Fact-checked lore, trauma with care, no glorification. Research before writing story beats.
